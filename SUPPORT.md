# Support 🌱
Stuck on something, or not sure where a question belongs? You're in
the right place. Same spirit as everywhere else in this project: there's
no such thing as a "dumb question" here.
## Using py-simple-wrap and stuck on something?
Start with the [documentation site](https://sara-czasak.github.io/py-simple-wrap/docs/) —
the [Quickstart](https://sara-czasak.github.io/py-simple-wrap/docs/tutorial/quickstart/)
covers installation and your first few functions, the per-module
Tutorials walk through realistic examples, and the Reference section
has every function's full docstring.
Still stuck after that? Ask in the
[Discord](https://discord.gg/Ge5HnVw2p) — it's the fastest way to get
help, and a good place for "is this even possible with py_simple?"
style questions that aren't really bug reports.
## Found a bug?
[Open a GitHub Issue](https://github.com/sara-czasak/py-simple-wrap/issues/new/choose)
using whichever template fits. Include what you expected vs. what
actually happened, and a minimal code snippet if you can — that's the
single biggest thing that speeds up a fix.
## Have an idea for a new module or function?
Also a GitHub Issue — see the "New Module Suggestion" template, or open
one and we can brainstorm it together. [CONTRIBUTING.md](CONTRIBUTING.md)'s
"Simple Philosophy" section covers what tends to fit this project.
## Want to contribute code yourself?
That's not this file — see [CONTRIBUTING.md](CONTRIBUTING.md), which
has a full step-by-step guide even if you've never opened a pull
request before, plus the [Contributor Hub](https://sara-czasak.github.io/py-simple-wrap/docs/contributor-hub/)
for copy-paste docstring/tutorial templates.
## Found a security vulnerability?
Please don't open a public issue for this one — see
[SECURITY.md](SECURITY.md) for how to report it privately.
## Something about someone's behavior?
See the **Enforcement** section of
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for how to report it.
---
This is a solo-maintained project, so response times won't always be
instant — thanks for your patience, and for being here. 🌈✨
